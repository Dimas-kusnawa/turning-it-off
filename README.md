A program that writes one line to `/output/entry.txt` (132 characters, inside the 1–199 character gate): "Let's turn it off and on again — and if that fails, I'll transfer you to someone who will also tell you to turn it off and on again." The hopeless tech support agent offers the classic fix, then the escalation every caller dreads: being handed to another agent who will say the exact same thing.

## Run it

```sh
python3 main.py
```
